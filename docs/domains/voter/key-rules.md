# Eligibility Rules
|Rule|Reason
|--- | ---- 
|All three paths converge on EligibleVoter|Single source of truth for voting
|Bulk upload allowed after RegistrationClosed|Real-world requirement
|Feed path has minimal friction|Trusted source
|UI path has full challenge/incomplete flow|Highest fraud risk
|All terminal states allow re-application via new record|No one permanently blocked
|All state changes emit events to ElectionObserver|Full audit trail
